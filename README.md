# Tragamonedas CMillonario (prueba interna)

Prototipo de in-app para CleverTap (opción **URL** del editor Custom HTML). Uso interno, no publicado a usuarios.

- Juego: `https://czamorarios.github.io/TragamonedasCM/`
- Diagnóstico en pantalla: agregar `?debug=1`
- Los códigos `PRUEBA-*` son ficticios.

Se genera con `node build.mjs --hosted` desde el proyecto local `cm-inapp-games/tragamonedas`.
